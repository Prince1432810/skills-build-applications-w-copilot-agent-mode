# OctoFit Tracker

A modern multi-tier application for fitness tracking with team management and leaderboards.

## Project Structure

- **frontend/**: React 19 + Vite + Bootstrap application on port 5173
- **backend/**: Node.js + Express + TypeScript API on port 8000
- **database/**: MongoDB on port 27017

## Features

- User authentication and profiles
- Activity logging and tracking
- Team creation and management
- Competitive leaderboard
- Personalized workout suggestions

## Getting Started

### Frontend Setup
```bash
cd octofit-tracker/frontend
npm install
npm run dev
```

### Backend Setup
```bash
cd octofit-tracker/backend
npm install
npm run dev
```

### Database
MongoDB should be running on localhost:27017

## Stack

- **Presentation Tier**: React 19, Vite, React Router, Bootstrap
- **Logic Tier**: Node.js, Express, TypeScript
- **Data Tier**: MongoDB, Mongoose
